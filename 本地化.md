## 记录如何本地打包提交的maven中心

### 1、全局替换版本
2.0.3-SNAPSHOT  --> 2.0.3-local-SNAPSHOT

### 2、私服配置
```xml

<distributionManagement>
    <repository>
        <id>releases</id>
        <name>Project RELEASE</name>
        <url>https://st-test.quecinfo.com:8765/repository/maven-releases/</url>
    </repository>
    <snapshotRepository>
        <id>snapshots</id>
        <name>Porject SNAPSHOTS</name>
        <url>https://st-test.quecinfo.com:8765/repository/maven-snapshots/</url>
    </snapshotRepository>
</distributionManagement>

```
### 3、打包命令
cd /d D:\git\agentscope-java

mvn clean install -DskipTests
mvn clean deploy -DskipTests
